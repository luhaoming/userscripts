# 🚀 HackMD 筆記快速搜尋 (HackMD Search Pro)

這是一個專為 HackMD 使用者打造的全文檢索工具，讓您在瀏覽器中即可享受 Spotlight 般的秒級搜尋體驗。

---

## ✨ 核心特色

- **⚡ 秒級檢索**：索引完全存儲於本地瀏覽器（IndexedDB），輸入關鍵字即出結果。
- **🔄 智能增量同步**：
    - 自動比對遠端最後修改時間 (`lastChangedAt`)。
    - 僅下載有變動的文章，極大化節省流量與 API 請求次數。
- **🧹 自動垃圾回收 (GC)**：同步時會自動偵測並移除雲端已刪除的文章索引。
- **🎯 標籤檢索與特殊指令**：
    - 支援標題、內文、標籤全文檢索。
    - 輸入 `:un` 即可快速盤點所有「未分類」的文章。
- **🎨 快樂工具人品牌識別**：精緻的 UI 設計，提供流暢的開啟/關閉動畫與懸浮按鈕 (FAB)。

---

## 🛠️ 設定與使用指南

安裝腳本後，請依照以下步驟設定以啟用全文同步功能：

### 1. 獲取 HackMD API Token
1. 前往 [HackMD 設定頁面](https://hackmd.io/settings)。
2. 捲動到最下方的 **API 設定**。
3. 點擊「產生 API Token」並複製產出的 Token。

### 2. 在腳本中設定 Token
1. 在任何 HackMD 頁面按下 `Alt + S` 或點擊右下角的 🚀 懸浮按鈕開啟搜尋視窗。
2. 點擊左下角的 「⚙️ 設定 Token」。
3. 貼上剛才複製的 Token 並按確定。
4. 頁面將自動重新整理以套用設定。

### 3. 初次同步知識庫
1. 開啟搜尋視窗，點擊右上角的 「**同步知識庫**」。
2. 等待進度條完成（初次同步視筆記數量而定，後續皆為增量更新，速度極快）。
3. 同步完成後即可開始享受秒級搜尋。

## ⌨️ 快捷鍵與操作

| 動作 | 快捷鍵 / 操作 |
| :--- | :--- |
| **開啟 / 關閉搜尋視窗** | `Alt + S` 或 🚀 懸浮按鈕 |
| **關閉搜尋視窗** | `Esc` 或 點擊背景陰影區域 |
| **盤點未分類筆記** | 在搜尋框輸入 `:un` |
| **強制重新下載** | 勾選「強制覆寫」後點擊同步 |

---

## 🛡️ 安全與隱私

- **完全本地化**：您的 API Token 與所有筆記索引均僅存儲於瀏覽器的 `GM_setValue` 空間中。
- **無伺服器參與**：本腳本不會將您的資料傳送到任何第三方伺服器。
- **開源透明**：程式碼完全公開，您可以隨時審閱網路請求邏輯。
